# Images

The site shows a red halftone placeholder until these files exist. Place the
images you find (screenshots, official art) here with **exactly** these names:

| File | Used for |
| --- | --- |
| `kamoshida/ruler.jpg` | Portrait of Kamoshida in the header |
| `kamoshida/castle.jpg` | "Palace Intel" panel (e.g. a picture of the castle) |
| `kamoshida/will-seed.jpg` | The Will Seed markers |
| `kamoshida/boss.jpg` | Shadow Kamoshida marker (Throne Room) |
| `kamoshida/treasure.jpg` | The Treasure (Crown) marker |

Want an image for another marker? Add `image: 'kamoshida/<name>.jpg'` to that
marker in `src/data/kamoshida.js`.
